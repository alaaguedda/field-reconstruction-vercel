How this demo works

Kriging is fully live: the sensors you place (position, value, depth) are sent to the API, which runs real Ordinary Kriging using a variogram (nugget/sill/range) that was fit to the actual historical data and cross-validated for each depth — not auto-fit from your handful of points, which would be unstable with only a few sensors.

Tensor completion and the physics-informed neural network were trained once on the real historical sensor network and are queried directly by coordinate/depth/date — they do not react to sensors you add, because that's not how a trained model works. For a brand-new location, the tensor model's location-factors are interpolated from nearby trained sensors (a documented approximation, not a claim that point was ever observed).

No accuracy number is shown anywhere in this demo — the notebook's Stage 5 quantitative comparison (RMSE/MAE/R² per method) is the place to look for that.

Field dimensions mirror the real Cook Farm sensor-network extent from the companion notebook. This page calls a live backend serving the notebook's actual trained models (Stage 9) — it is not a static approximation.
